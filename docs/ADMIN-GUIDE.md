# Краткая инструкция администратора Nexor 1.5

Используйте только выданный отдельно актуальный least-privilege доступ. Старые реквизиты из переписки применять нельзя.

## Основные разделы

- Контакты, аналитика, ставки калькулятора и новые блоки главной: **Настройки → Nexor**.
- Меню: **Внешний вид → Меню** — locations `primary`, `mobile`, `footer`.
- Страницы услуг: **Страницы** → одна из шести опубликованных услуг → блок **Структура услуги и перелинковка**.
- Проекты: **Проекты**; изображения и alt: **Медиафайлы**.
- Заявки: **Заявки**. Telegram error не удаляет заявку; доступна повторная отправка.

## Новые блоки главной

Каждая секция имеет общий флажок и флажок строки. Пустая/невалидная секция полностью скрыта вместе с пунктом меню.

- **Цены и сроки:** добавьте stable ID, порядок, страницу услуги, подписи цены/срока, примечание и CTA. Дисклеймер обязателен.
- **Видео:** укажите attachment ID либо согласованный URL, poster ID, при наличии captions ID и транскрипт. Autoplay отсутствует.
- **Дополнительные услуги:** stable ID, порядок, название, описание, CTA. `cta_mode=form` передаёт выбор в заявку; `link` требует URL.
- **Акции:** пять записей создаются выключенными. Для публикации обязательны условия и юридический текст. Не включайте до согласования.
- **Отложенный popup:** заполните заголовок, текст, предложение и CTA. Popup автоматически показывается всем пользователям после заданной задержки. По умолчанию выключен.
- **Stages (новая секция этапов):** stable ID, порядок, название, описание и изображение через кнопку «Выбрать изображение» (медиатека). Надпись над заголовком, заголовок и подзаголовок редактируются отдельно. Кнопка «Записаться на замер» на карточке фиксирована и не настраивается. Секция `#stages` выводится на главной. Без выбранного изображения этап рендерится без картинки.

## Главная 1.5

- Hero главной рендерится из `template-parts/home-hero-section.php`; акционный баннер в hero берётся из **Настройки → Nexor** (featured-бонус и дедлайн). Этапы — из тех же настроек, не из HTML страницы.
- **Таблица сроков**, **Как мы держим смету**, **Дополнительные услуги**, **Бонусы** и **Отложенный popup** редактируются в **Настройки → Nexor**.
- Для временного баннера бонусов доступны включение, stable ID бонуса, надпись и дедлайн ISO 8601. В hero публично показывается только «Дизайн-проект в подарок» и таймер.
- Основные услуги используют опубликованные страницы услуг и их поля; косметический ремонт остаётся отдельной страницей и на главной не выводится.
- **Реализованные проекты (главная):** заголовок, описание, CTA и ровно три фиксированные карточки редактируются в **Настройки → Nexor**. Stable ID = slug проекта и не меняется; можно указать ID CPT `nexor_project`. Пустые заголовок, подпись, бейдж и изображение берутся из карточки проекта.
- Поля настроек принимают только текст, числа, URL и построчные списки; произвольный HTML не поддерживается намеренно.

## Услуги и перелинковка

- Не меняйте slug шести существующих страниц.
- Поля состава работ заполняются по одной строке.
- FAQ: одна строка в формате `Вопрос | Ответ`.
- Связанные проекты и материалы: публичные WordPress post IDs через запятую; выводится максимум шесть ссылок, drafts/private игнорируются.

## Поиск и SEO

- Поиск охватывает только published `page`, `post`, `nexor_project`; заявки, attachments и private entities исключены.
- Search results имеют `noindex, follow` и не входят в sitemap.
- Sitemap: `/wp-sitemap.xml`; robots: `/robots.txt`.
- Калькулятор не изменён и продолжает серверную перепроверку.

## Диагностика

Без изменения данных: `wp nexor enhancements-diagnostic`. Команда выводит только версии/counts/enabled state и не выводит секреты.
