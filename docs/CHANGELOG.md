# Changelog

## Не выпущено

- Секция «Этапы» на главной показывает один этап за раз: медный ползунок сверху круга крутится мышкой/пальцем по часовой стрелке и плавно сменяет изображение и текст этапа (GSAP Draggable + InertiaPlugin, доводка по 72°).
- Пронумерованные этапы под карточкой работают как пагинация: подсвечивают активный этап и доворачивают круг к выбранному этапу; добавлены клавиатурное управление ползунком (стрелки, Home/End) и дуга прогресса.
- Пока посетитель не взялся за ползунок, он пружинит по кругу с паузами (не дальше половины шага, поэтому этап не меняется), а при первом появлении секции рядом всплывает подсказка «Потяните по кругу». Анимация останавливается на первом взаимодействии, замирает вне экрана и не запускается при `prefers-reduced-motion`.
- Удалена старая секция «Как мы делаем ремонт предсказуемым» (`nexor-process-section` / `#work-stages`) — её дублировала новая интерактивная карточка этапов. Блок вырезается из уже сохранённого контента главной при рендере, удалён из seed-разметки, а его JS и CSS убраны из темы.
- Секция «Как нам это удаётся?» (`#budget-control`): подпись под показателем «0%» перенесена из правой колонки под саму цифру и отделена тонкой линией — по референсу. Заодно устранены задвоенные и частично мёртвые mobile-правила `.nexor-budget__*` в `nexor.css`.
